# 2027 裁判系统串口 UI 协议支持边界

所有协议规则均以 RoboMaster 2027 串口通信协议 `0x0301`（`0x0100 ~ 0x0110`）及附录二为准。

## 1. 画布与双色板隔离红线

- **App Shell 外壳**：支持暗色（`Dark Studio`）与浅色（`Light Precision`）主题切换、磨砂玻璃质感（`.mk-glass` / `.mk-glass-elevated`）与微动效。
- **1920×1080 客户端画布内部**：**严禁出现渐变、阴影、发光、模糊、圆角矩形及协议 9 色以外的任意 HEX 颜色**，确保编辑器内所见即赛场客户端所见。
- **坐标系**：存储与交换统一采用 **RM 左下角原点** `(0,0) → (1920,1080)`；通过 `src/domain/protocol/geometry.ts` 显式换算至 Konva 左上角原点，禁止翻转 Layer `scaleY`。

## 2. 支持的 8 类基本图元与 9 种协议色

- **8 类图元（`figure_tpye 0..7`）**：直线 (`line`)、矩形 (`rect`)、正圆 (`circle`)、椭圆 (`ellipse`)、圆弧 (`arc`，0° 在 12 点钟正上方顺时针递增)、浮点数 (`float`，按 `int32(round(val * 1000))` 编码)、整型数 (`int`)、字符 (`text`，UTF-8 ≤ 30 字节)。
- **9 种颜色（`0..8`）**：`0=红蓝主色 (main)`、`1=黄`、`2=绿`、`3=橙`、`4=紫红`、`5=粉`、`6=青`、`7=黑`、`8=白`。

## 3. 分包、带宽与 ID 约束

- **短名唯一性**：`figure_name[3]` 限 1~3 字节且在同一画面内唯一；粘贴/再制时自动分配不冲突短名。
- **分包规则**：每个 `text` 独占 1 帧 `0x0110`（60 B）；其余 7 类图形按分组以 7/5/2/1 拆包（对应 `0x0104` 120B / `0x0103` 90B / `0x0102` 45B / `0x0101` 30B）。
- **2027 角色与链路限额**：`0x0301` 上行上限 **30 Hz**；每 1000 ms 基准额度 **3720 B**（重装 `#1`、步兵 `#3/#4/#5`、空中 `#6`）或 **5120 B**（哨兵 `#7`）；`2/102` 为保留位。
