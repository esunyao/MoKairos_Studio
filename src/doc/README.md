# 前端概览

React 与 TypeScript 前端负责设计者在桌面窗口内使用的编辑交互和界面展示，Vite 提供开发服务与构建。保存和模拟验证属于后续产品能力，任务启动时再明确交互范围。

- [main.tsx](../main.tsx) 装载 React 应用，[App.tsx](../App.tsx) 承载当前画布原型，[App.css](../App.css) 提供样式。
- 组件使用的资源见 [src/assets](../assets/)，静态资源见 [public](../../public/)。
- 涉及桌面能力或代码生成时，沿[Rust 模块导航](../../src-tauri/AGENTS.md)核对另一侧的职责和实际入口。
