# MoKairos Studio

面向 RoboMaster 的桌面 UI 设计工具。项目目标包括可视化编辑、保存、模拟验证，以及通过 Rust 生成可接入整车 CMake 构建的 UI 产物。当前仓库处于原型阶段。

从[项目概览](doc/README.md)了解模块与目标，从[仓库指南](AGENTS.md)查看开发命令和贡献规范。
